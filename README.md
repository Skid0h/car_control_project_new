# Car Control Project

**Тестовая роботизированная платформа для разработки и проверки систем автономного движения.**

Проект предназначен для отработки компьютерного зрения, алгоритмов движения по конусной трассе и взаимодействия с исполнительными механизмами перед дальнейшим внедрением на беспилотный болид **Driverless**.

В основе платформы — **NVIDIA Jetson Xavier**, камера **ZED** и **Arduino**. Система поддерживает ручное управление с ПК, автономное движение по конусам, передачу телеметрии и запись заездов.

> Экспериментальный проект для испытаний на закрытой контролируемой площадке. Не предназначен для эксплуатации на дорогах общего пользования.

## Назначение

Платформа позволяет проверять программно-аппаратные решения на небольшом автомобиле до их переноса на полноразмерный болид.

Основные задачи:

- Распознавание конусов и определение границ трассы.
- Проверка алгоритмов планирования и рулевого управления.
- Взаимодействие бортового компьютера с контроллером приводов.
- Переключение между ручным и автономным режимами.
- Анализ поведения системы по видео и телеметрии.
- Отработка реакции на потерю данных и связи.

Это исследовательская платформа, а не готовая система автономного управления болидом.

## Версии проекта

**Проект активно развивается. На данный момент существуют три крупных направления: базовая Python-реализация, улучшенная Python-версия и переход на ROS 2.**

### v1.0 — Python (базовая)

Базовая версия без ROS: обработка камеры, распознавание конусов и логика управления объединены в одном Python-приложении.

- Детекция конусов через Ultralytics YOLO.
- Базовое движение по конусной трассе.
- Управление Arduino по UART.
- Пульт на Pygame с UDP-обменом.
- Телеметрия, веб-видеотрансляция и запись заездов.

### v1.1 — Python (улучшенная)

Обновлённая Python-версия с исправлением критических ошибок и повышением стабильности автономного режима.

Ключевые улучшения относительно v1.0:

**Исправление критических ошибок:**
- Исправлена утечка памяти: система больше не накапливает текстуры камеры, память освобождается автоматически.
- Добавлены проверки деления на ноль в расчётах глубины и углов.
- Исправлена ошибка обработки потерянных целей (ранее система обращалась к несуществующим данным и аварийно завершалась).
- Улучшен парсинг команд управления скоростью с обработкой некорректного ввода.
- Устранена избыточность синхронизации потоков для повышения производительности.

**Улучшение автономного управления:**
- Внедрён полноценный PID-регулятор руля с фильтрацией ошибок и защитой от насыщения интеграла.
- Реализован алгоритм Pure Pursuit с адаптивной дистанцией упреждения для более плавного движения по трассе.
- Добавлена поддержка режимов глубины камеры ZED для более точного определения расстояния.
- Реализована плавная остановка при потере детекции конусов (graceful degradation) вместо резкого торможения.

**Оптимизация и мониторинг:**
- Добавлен двойной счётчик FPS: отдельно отслеживается частота захвата кадров и обработки детекции.
- Оптимизирована запись видео с проверкой свободного места на диске перед началом записи.
- Улучшена обработка команд от пульта с защитой от некорректных данных.
- Повышена отзывчивость веб-интерфейса за счёт более эффективной синхронизации потоков.

Совместимость с пультом и Arduino v1.0 полностью сохранена.

### v2.0 — переход на ROS 2

Развиваемая версия с модульной архитектурой на **ROS 2 Foxy**.

Ключевые изменения относительно v1.x:

- Разделение восприятия и управления на отдельные ноды.
- Обмен данными через ROS 2-топики.
- Обновление алгоритма управления: интерполяция границ, сглаживание и PID.
- Прямой инференс через TensorRT и PyCUDA.
- Расширение контроля таймаутов и ограничений команд приводам.
- Добавление диагностики, режима `dry_run` и автоматизированных тестов.

Совместимость с существующим UDP-пультом сохранена.

Релизы доступны в разделе [Releases](https://github.com/Skid0h/car_control_project_new/releases).

## Основные возможности

### Компьютерное зрение

- Работа с камерой ZED через ZED SDK.
- Распознавание синих, жёлтых и оранжевых конусов.
- Настройка порогов уверенности и IoU.
- Оценка расстояния до конусов по площади рамки объекта.
- Расчёт приблизительного бокового положения по калибровке камеры.
- **v1.1:** Поддержка режимов глубины ZED для повышения точности измерений.

### Управление автомобилем

- Ручное движение вперёд и назад.
- Управление рулевым сервоприводом.
- Автономное движение по конусной трассе.
- Перехват управления оператором.
- Остановка перед оранжевым стоп-конусом.
- **v1.1:** PID-регулятор руля с EMA-фильтрацией и анти-windup.
- **v1.1:** Алгоритм Pure Pursuit с адаптивной дистанцией упреждения.
- **v1.1:** Плавная остановка при потере детекции (graceful degradation).

### Мониторинг

- Передача состояния системы на ПК.
- Отображение режима, состояния камеры и записи.
- Просмотр аннотированного видео в браузере.
- Запись заездов для последующего анализа.
- **v1.1:** Двойной счётчик FPS (захват и обработка детекции).
- **v1.1:** Проверка свободного места на диске перед записью.

### Контроль состояния

- Проверка диапазонов управляющих значений.
- Остановка по таймаутам команд.
- Watchdog на Arduino.
- **v1.1:** Проверки деления на ноль в расчётах глубины и углов.
- **v1.1:** Обработка потерянных целей без аварийного завершения.
- В версии 2.0 — дополнительный контроль свежести данных, потери связи с пультом и динамики рулевых команд.

## Архитектура

```text
                         Камера ZED
                             │
                             ▼
ПК оператора ◄── UDP ──► Jetson Xavier ── UART/USB ──► Arduino
                             │                          │
                             ├── Обработка изображения  ├── ESC двигателя
                             ├── Автономное управление  └── Рулевой сервопривод
                             ├── Телеметрия
                             └── Видео и запись
```

- **Jetson Xavier** — обработка изображения, распознавание конусов, расчёт команд и обмен с оператором.
- **Arduino** — управление двигателем и рулевым сервоприводом, проверка команд и watchdog.
- **ПК оператора** — ручное управление, переключение режимов и отображение состояния системы.

## Подготовка и запуск

### Общие требования

Перед запуском необходимо:

1. Подготовить совместимую среду JetPack, CUDA, ZED SDK и Python.
2. Указать путь к обученной модели распознавания конусов.
3. Проверить соответствие классов модели конфигурации.
4. Настроить IP-адрес Jetson и порт в пульте.
5. Проверить прошивку Arduino.
6. Откалибровать нейтраль ESC, центр и пределы рулевого управления.
7. Проверить реакцию на STOP и потерю связи.

### Настройка v1.1

В версии 1.1 добавлены новые параметры конфигурации в файле `config.jsonc`:

**Блок PID-регулятора (`pid`):**
- `kp_gain`, `ki_gain`, `kd_gain` — коэффициенты пропорциональной, интегральной и дифференциальной составляющих.
- `ema_alpha` — коэффициент сглаживания ошибки (экспоненциальное скользящее среднее).
- `max_integral` — ограничение интегральной составляющей (защита от насыщения).
- `min_dt` — минимальный интервал времени для расчёта производной.

**Блок Pure Pursuit (`pure_pursuit`):**
- `lookahead_base` — базовая дистанция упреждения в метрах.
- `lookahead_speed_factor` — коэффициент увеличения дистанции при росте скорости.
- `lookahead_min`, `lookahead_max` — границы дистанции упреждения.

**Блок graceful degradation (`graceful_degradation`):**
- `enabled` — включение плавной остановки при потере детекции.
- `deceleration_rate` — скорость снижения тяги при потере цели.
- `min_throttle` — минимальная тяга при деградации.

**Блок записи (`recording`):**
- `min_free_space_gb` — минимальное свободное место на диске для начала записи (в гигабайтах).

Все параметры имеют значения по умолчанию и могут быть настроены под конкретное оборудование.

## Управление

Основные клавиши пульта:

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓` | Движение вперёд / назад |
| `←` / `→` | Поворот |
| `A` | Включить автономный режим |
| `S` | Остановиться и перейти в ручной режим |
| `R` | Начать запись |
| `C` | Остановить запись |
| `1` / `2` | Уменьшить / увеличить настройку тяги |
| `Q` | Отправить команду остановки и завершения |

Ненулевая команда движения или поворота позволяет оператору перехватить управление.

Видеотрансляция при включённом веб-сервере:

```text
http://<JETSON_IP>:5000/
```

В ROS 2-версии веб-сервер по умолчанию отключён.

## Ограничения и безопасность

- Расстояние до конусов оценивается по размеру рамки, а не по карте глубины ZED. Точность зависит от калибровки, ракурса и качества детекции.
- Алгоритмы не обеспечивают универсальное обнаружение препятствий и безопасное движение в произвольной среде.
- Перевод ESC в нейтраль не означает активное торможение: машина может продолжать катиться.
- Значения тяги, центра и углов руля не являются универсальными для любого оборудования.
- В v1.x потеря связи с ПК не является условием остановки в автономном режиме.
- Исходный Arduino-скетч v1.0 требует проверки перед компиляцией: в нём присутствует лишний символ `\`, а аварийный центр руля необходимо согласовать с конфигурацией.
- UDP-пульт и веб-трансляцию следует использовать только в доверенной изолированной сети.
- Автоматизированные тесты не заменяют испытания на целевом Jetson, проверку GPU и калибровку механики.

### Улучшения безопасности в v1.1

- Добавлены проверки деления на ноль во всех расчётах глубины и углов.
- Система корректно обрабатывает потерю детекции конусов без аварийного завершения.
- Реализована плавная остановка при потере цели вместо резкого торможения.
- Добавлена проверка свободного места на диске перед началом записи видео.
- Улучшен парсинг команд управления с защитой от некорректных данных.

## Развитие проекта

Основное направление — развитие модульной системы на ROS 2 и подготовка алгоритмов к переносу на болид Driverless.

Дальнейшая работа включает:

- Проверку ROS 2-приложения на целевом оборудовании.
- Настройку и оценку качества распознавания.
- Калибровку камеры и приводов.
- Проверку поведения при отказах и задержках данных.
- Развитие планирования траектории и управления скоростью.
- Подключение дополнительных датчиков.
- Постепенную интеграцию с системами болида.

Ошибки, предложения и результаты испытаний можно публиковать в [Issues](https://github.com/Skid0h/car_control_project_new/issues).
