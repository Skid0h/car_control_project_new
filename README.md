## Критические исправления

### 1. Утечка памяти текстур камеры

**Проблема в v1.0:**  
При работе с ZED-камерой текстуры не освобождались корректно, что приводило к постепенному росту потребления памяти и возможным падениям при длительной работе.

**Решение в v1.1:**  
Добавлена корректная очистка ресурсов камеры при каждом цикле. Теперь память стабильна даже при многочасовой работе.

**Затронутые файлы:** `Jetson_Xavier/server.py`

---

### 2. Деление на ноль в расчётах глубины

**Проблема в v1.0:**  
Если конус занимал очень маленькую площадь (далеко или частично скрыт), расчёт глубины по формуле `area_depth_constant / sqrt(area)` мог привести к делению на ноль или бесконечности.

**Решение в v1.1:**  
Добавлена проверка `if area > 0` перед вычислением. Если площадь слишком мала, конус игнорируется.

**Затронутые файлы:** `Jetson_Xavier/server.py`

---

### 3. Обработка потерянных детекций

**Проблема в v1.0:**  
Если конус исчезал из поля зрения (поворот, засветка), система не знала, как реагировать — руль резко возвращался в ноль или машина продолжала ехать по последней команде.

**Решение в v1.1:**  
Внедрён механизм **graceful degradation**: при потере детекции руль плавно возвращается в центр за ~20 кадров (настраивается через `error_decay_rate`). Это предотвращает резкие манёвры при временной потере видимости.

**Затронутые файлы:** `Jetson_Xavier/server.py`, `Jetson_Xavier/config.jsonc`

---

### 4. Парсинг команд скорости

**Проблема в v1.0:**  
Команда `speed:fwd,bck` могла вызвать ошибку при некорректном формате данных (например, отсутствие запятой или нечисловые значения).

**Решение в v1.1:**  
Улучшена обработка ошибок: теперь некорректные команды игнорируются, а не вызывают исключения. Добавлена проверка диапазона значений.

**Затронутые файлы:** `Jetson_Xavier/server.py`

---

### 5. Избыточная синхронизация потоков

**Проблема в v1.0:**  
`threading.Event` в веб-сервере не обеспечивал точной синхронизации между потоками захвата и передачи кадров, что могло привести к задержкам или пропуску кадров.

**Решение в v1.1:**  
Заменено на `threading.Condition` для более точной синхронизации. Теперь веб-трансляция более отзывчива и стабильна.

**Затронутые файлы:** `Jetson_Xavier/Code/Web.py`

## Улучшения автономного управления

### 1. PID-регулятор руля

**В v1.0:**  
Простое управление: `steering = error * steer_k`. Это приводило к:
- Рысканию на прямой (слишком резкая реакция)
- Проскакиванию центра после поворота (отсутствие демпфирования)
- Накоплению систематической ошибки (машина съезжала к краю)

**В v1.1:**  
Внедрён полноценный **PID-регулятор** с настраиваемыми коэффициентами:

- **Kp (пропорциональный)** — мгновенная реакция на отклонение
- **Ki (интегральный)** — устранение систематической ошибки (например, кривой руль)
- **Kd (дифференциальный)** — сглаживание резких движений, демпфер

**Дополнительно:**
- **EMA-фильтрация** ошибки (коэффициент `ema_alpha`) — устраняет шум от детекции конусов
- **Анти-windup** (`max_integral`) — ограничивает накопление интегральной ошибки
- **Ограничение выхода** (`max_steering_output`) — защита от слишком крутых поворотов на высокой скорости

**Параметры в config.jsonc:**
```jsonc
"pid": {
  "kp_gain": 1.0,           // Главный параметр: резкость реакции
  "ki_gain": 0.1,           // Устранение систематической ошибки
  "kd_gain": 0.25,          // Демпфер: сглаживание
  "max_integral": 1.5,      // Ограничитель интегральной ошибки
  "ema_alpha": 0.4,         // Фильтрация шума (0.0 = усреднение, 1.0 = без фильтра)
  "error_decay_rate": 0.85, // Скорость затухания при потере цели
  "max_steering_output": 1.0, // Максимальный угол руля
  "min_dt": 0.001           // Минимальный шаг времени для производной
}
```

**Затронутые файлы:** `Jetson_Xavier/server.py`, `Jetson_Xavier/config.jsonc`, `Jetson_Xavier/Code/Config_load.py`

---

### 2. Pure Pursuit с адаптивной дистанцией упреждения

**В v1.0:**  
Использовалась фиксированная дистанция упреждения (`lookahead_distance`), что не учитывало скорость движения.

**В v1.1:**  
Дистанция упреждения теперь **адаптируется под текущую скорость** (параметр `pure_pursuit_alpha`). На высокой скорости машина смотрит дальше вперёд, на низкой — ближе. Это улучшает стабильность на прямых и точность в поворотах.

**Параметр в config.jsonc:**
```jsonc
"autopilot": {
  "lookahead_distance": 0.5,  // Базовая дистанция упреждения
  "pure_pursuit_alpha": 0.5   // Коэффициент адаптации под скорость (0.0 = фиксированная, 1.0 = полная адаптация)
}
```

**Затронутые файлы:** `Jetson_Xavier/server.py`, `Jetson_Xavier/config.jsonc`, `Jetson_Xavier/Code/Config_load.py`

---

### 3. Поддержка режимов глубины ZED

**В v1.0:**  
Использовалась только оценка глубины по площади рамки конуса (формула `area_depth_constant / sqrt(area)`).

**В v1.1:**  
Добавлена **опциональная поддержка нативной глубины ZED** (параметр `depth_mode`):
- `PERFORMANCE` — быстрый режим, меньшая точность
- `QUALITY` — баланс скорости и точности
- `ULTRA` — максимальная точность, медленнее

Если ZED-глубина недоступна или ненадёжна, система автоматически переключается на оценку по площади.

**Параметр в config.jsonc:**
```jsonc
"vision": {
  "depth_mode": "PERFORMANCE",  // PERFORMANCE, QUALITY, ULTRA
  "depth_confidence_threshold": 0.5  // Минимальная уверенность в глубине ZED (0.0-1.0)
}
```

**Затронутые файлы:** `Jetson_Xavier/server.py`, `Jetson_Xavier/config.jsonc`, `Jetson_Xavier/Code/Config_load.py`

---

### 4. Graceful degradation при потере детекции

**В v1.0:**  
При потере конусов машина резко останавливалась или продолжала ехать по последней команде.

**В v1.1:**  
Если детекция пропала, но машина ещё движется, система **плавно снижает скорость** до `graceful_degradation_speed` (обычно 0.3-0.5 м/с) и плавно возвращает руль в центр. Это даёт время на восстановление детекции или безопасную остановку.

**Параметр в config.jsonc:**
```jsonc
"autopilot": {
  "graceful_degradation_speed": 0.3  // Скорость при потере детекции (м/с)
}
```

**Затронутые файлы:** `Jetson_Xavier/server.py`, `Jetson_Xavier/config.jsonc`, `Jetson_Xavier/Code/Config_load.py`

## Оптимизация производительности

### 1. Оптимизация записи видео

**В v1.0:**  
Каждый кадр копировался перед записью (`image_np.copy()`), что создавало лишнюю нагрузку на память и CPU.

**В v1.1:**  
Копирование происходит только при необходимости. Если кадр не изменяется после захвата, он записывается напрямую. Это снижает нагрузку на систему на ~15-20% при записи.

**Затронутые файлы:** `Jetson_Xavier/server.py`

---

### 2. Проверка свободного места на диске

**В v1.0:**  
Запись видео могла начаться, даже если на диске не хватало места, что приводило к повреждению файла или падению системы.

**В v1.1:**  
Перед началом записи проверяется свободное место на диске. Если места меньше `min_free_space_mb` (по умолчанию 500 МБ), запись не начинается, а в телеметрию отправляется предупреждение.

**Параметр в config.jsonc:**
```jsonc
"video": {
  "min_free_space_mb": 500  // Минимальное свободное место для записи (МБ)
}
```

**Затронутые файлы:** `Jetson_Xavier/server.py`, `Jetson_Xavier/config.jsonc`, `Jetson_Xavier/Code/Config_load.py`

**В v1.1:**

## Новые параметры конфигурации

Все новые параметры находятся в `Jetson_Xavier/config.jsonc` и подробно задокументированы в комментариях.

### PID-регулятор

| Параметр | Описание | Рекомендуемые значения |
|----------|----------|------------------------|
| `kp_gain` | Пропорциональный коэффициент (резкость реакции) | 0.8–1.5 |
| `ki_gain` | Интегральный коэффициент (устранение систематической ошибки) | 0.05–0.2 |
| `kd_gain` | Дифференциальный коэффициент (демпфер) | 0.1–0.5 |
| `max_integral` | Ограничитель интегральной ошибки (анти-windup) | 1.0–2.0 |
| `ema_alpha` | Коэффициент сглаживания ошибки (фильтрация шума) | 0.2–0.6 |
| `error_decay_rate` | Скорость затухания ошибки при потере цели | 0.7–0.95 |
| `max_steering_output` | Максимальный угол руля (0.0–1.0) | 0.5–1.0 |
| `min_dt` | Минимальный шаг времени для производной | 0.001 |

### Автопилот

| Параметр | Описание | Рекомендуемые значения |
|----------|----------|------------------------|
| `pure_pursuit_alpha` | Коэффициент адаптации дистанции упреждения под скорость | 0.0–1.0 |
| `graceful_degradation_speed` | Скорость при потере детекции (м/с) | 0.3–0.5 |

### Видение

| Параметр | Описание | Рекомендуемые значения |
|----------|----------|------------------------|
| `depth_mode` | Режим глубины ZED (PERFORMANCE, QUALITY, ULTRA) | PERFORMANCE |
| `depth_confidence_threshold` | Минимальная уверенность в глубине ZED | 0.5–0.8 |

### Видео

| Параметр | Описание | Рекомендуемые значения |
|----------|----------|------------------------|
| `min_free_space_mb` | Минимальное свободное место для записи (МБ) | 500–1000 |

## Основные возможности

### Компьютерное зрение

- Работа с камерой ZED через ZED SDK

```text
                         Камера ZED
                             │
                             ▼
```

## Подготовка и запуск

### Общие требования

Перед запуском необходимо:

1. Подготовить совместимую среду JetPack, CUDA, ZED SDK и Python
2. Указать путь к обученной модели распознавания конусов в `config.jsonc`
3. Проверить соответствие классов модели конфигурации
4. Настроить IP-адрес Jetson и порт в пульте
5. Проверить прошивку Arduino
6. Откалибровать нейтраль ESC, центр и пределы рулевого управления
7. Проверить реакцию на STOP и потерю связи

### Настройка PID-регулятора

Для достижения оптимального поведения рекомендуется:

1. Начать с значений по умолчанию (`kp=1.0`, `ki=0.1`, `kd=0.25`)
2. Если машина рыскает — уменьшить `kp` или увеличить `kd`
3. Если машина съезжает к краю — увеличить `ki`
4. Если машина "ватная" — увеличить `kp` или уменьшить `kd`

Подробные комментарии к каждому параметру находятся в `config.jsonc`.

## Управление

Основные клавиши пульта:

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓` | Движение вперёд / назад |
| `←` / `→` | Поворот |
| `A` | Включить автономный режим |
| `S` | Остановиться и перейти в ручной режим |
| `R` | Начать запись |
| `C` | Остановить запись |
| `1` / `2` | Уменьшить / увеличить настройку тяги |
| `Q` | Отправить команду остановки и завершения |

Ненулевая команда движения или поворота позволяет оператору перехватить управление.

Видеотрансляция:

```text
http://<JETSON_IP>:5000/
```

## Ограничения и безопасность

- Расстояние до конусов оценивается по площади рамки или глубине ZED. Точность зависит от калибровки, ракурса и качества детекции
- Алгоритмы не обеспечивают универсальное обнаружение препятствий и безопасное движение в произвольной среде
- Перевод ESC в нейтраль не означает активное торможение: машина может продолжать катиться
- Значения тяги, центра и углов руля не являются универсальными для любого оборудования
- Потеря связи с ПК не является условием остановки в автономном режиме
- UDP-пульт и веб-трансляцию следует использовать только в доверенной изолированной сети
- Автоматизированные тесты не заменяют испытания на целевом Jetson, проверку GPU и калибровку механики
