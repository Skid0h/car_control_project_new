# Car Control Project

Система ручного и автономного управления роботизированным автомобилем на базе **NVIDIA Jetson Xavier**, **Arduino** и камеры **ZED**.

Проект объединяет распознавание дорожных конусов с помощью YOLO, построение целевых точек движения, управление двигателем и рулевым сервоприводом, удалённый пульт оператора, видеотрансляцию и запись заездов.

> Экспериментальный проект для работы на контролируемой конусной трассе. Не предназначен для эксплуатации на дорогах общего пользования.

## Архитектура

Система состоит из трёх основных компонентов:

```text
                         Камера ZED
                             │
                             ▼
ПК оператора ◄── UDP ──► Jetson Xavier ── UART ──► Arduino
                             │                      │
                             ▼                      ├── ESC двигателя
                    Веб-видеотрансляция             └── Рулевой сервопривод
```

### NVIDIA Jetson Xavier

Бортовой вычислительный модуль:

- Получает изображения с камеры ZED.
- Запускает детектор конусов.
- Рассчитывает целевые точки и команды автономного движения.
- Принимает команды оператора.
- Передаёт команды на Arduino.
- Отправляет телеметрию на ПК.
- Обеспечивает видеотрансляцию и запись.

### Arduino

Контроллер исполнительных механизмов:

- Принимает команды по последовательному порту.
- Управляет ESC двигателя и рулевым сервоприводом.
- Проверяет диапазоны полученных значений.
- Переводит двигатель в нейтраль при отсутствии корректных команд.

### ПК оператора

Графический пульт на Pygame:

- Управление автомобилем с клавиатуры.
- Переключение режимов.
- Изменение настроек тяги.
- Управление видеозаписью.
- Отображение состояния системы.

## Возможности

### Компьютерное зрение

- Получение видеопотока через ZED SDK.
- Распознавание синих, жёлтых и оранжевых конусов с помощью Ultralytics YOLO.
- Настраиваемые пороги уверенности и IoU.
- Получение рамок объектов, классов, уверенности и опорных точек.
- Оценка расстояния до конусов по площади их рамок.
- Расчёт приблизительного бокового положения объектов с использованием калибровки камеры.
- Уменьшение и обрезка изображения перед детекцией.
- Настраиваемая частота обработки кадров.
- Использование CUDA для инференса и отдельных операций OpenCV при наличии совместимой среды.

### Автономное управление

- Сопоставление синих и жёлтых конусов в пары.
- Построение целевых точек в серединах найденных пар.
- Формирование виртуальных точек от одиночных конусов, если пары не найдены.
- Выбор ближайшей целевой точки.
- Расчёт рулевого управления по угловому отклонению от цели.
- Остановка перед оранжевым стоп-конусом.
- Перехват управления оператором при поступлении ненулевой ручной команды.

### Ручное управление

- Движение вперёд и назад.
- Поворот колёс влево и вправо.
- Переключение между ручным и автоматическим режимами.
- Изменение управляющих значений двигателя во время работы.
- Отправка команд по UDP с частотой 20 циклов в секунду.
- Отдельный пример прямого управления Arduino с ПК через последовательный порт.

### Телеметрия

Сервер возвращает состояние системы в формате JSON:

- Режим работы: `AUTO` или `MANUAL`.
- Состояние видеозаписи.
- Статус подключения камеры.
- Статус подключения Arduino.
- Настройки тяги вперёд и назад.
- Системные сообщения.

Пульт отображает состояние связи, камеры, записи, текущий режим и подтверждённые сервером настройки тяги.

### Видеотрансляция и запись

- Просмотр изображения в браузере через Flask и MJPEG.
- Отрисовка рамок и классов конусов.
- Отображение пар конусов, линии траектории и целевой точки.
- Наложение режима работы, счётчика кадров, оценочного расстояния и индикатора записи.
- Запись обработанного видео в отдельном потоке.
- Использование очереди кадров для отделения записи от основного цикла обработки.
- Сохранение временного видео в AVI/MJPEG.
- Фоновая конвертация в MP4/H.264 через FFmpeg.
- Имена файлов с временными метками.

### Остановка и восстановление подключения

- Автоматический поиск Arduino по USB-описанию и VID.
- Отправка нейтральной команды при открытии и закрытии соединения.
- Программный watchdog в ручном режиме.
- Failsafe на Arduino с таймаутом 500 мс.
- Попытка переподключения камеры после серии ошибок захвата.
- Серверная команда повторной инициализации Arduino и камеры.

## Алгоритм автономного движения

1. **Получение кадра**  
   Jetson получает изображение с левой камеры ZED.

2. **Предобработка**  
   Кадр уменьшается и обрезается перед передачей детектору.

3. **Детекция конусов**  
   YOLO определяет положение и класс каждого обнаруженного конуса.

4. **Оценка координат**  
   Расстояние оценивается по площади рамки:

   ```text
   distance = area_depth_constant / sqrt(bbox_area)
   ```

   Боковое смещение рассчитывается по положению объекта в кадре и параметрам калибровки камеры.

5. **Построение целевых точек**  
   Синие и жёлтые конусы сопоставляются по близости глубины и допустимому поперечному расстоянию. Центры пар становятся целевыми точками.

   Если пары отсутствуют, точки формируются со смещением от одиночных конусов. При наличии хотя бы одной пары виртуальные точки не добавляются.

6. **Управление движением**  
   Выбирается ближайшая целевая точка. Угол направления на неё преобразуется в нормализованную команду рулевого управления.

7. **Остановка на финише**  
   При приближении к оранжевому конусу ближе заданного порога автомобиль получает команду остановки, а автоматический режим отключается.

## Управление

Клавиши основного пульта `PC/server_send.py`:

| Клавиша | Действие |
| --- | --- |
| `↑` | Движение вперёд |
| `↓` | Движение назад |
| `←` / `→` | Поворот |
| `A` | Включить автономный режим |
| `S` | Отключить автономный режим и остановиться |
| `R` | Начать запись видео |
| `C` | Остановить запись видео |
| `1` | Приблизить значения тяги к нейтрали |
| `2` | Увеличить отклонение значений тяги от нейтрали |
| `Q` | Отправить команду завершения серверу и закрыть пульт |

> В автономном режиме ненулевая команда движения или поворота переключает систему на ручное управление.

Видеотрансляция доступна по адресу:

```text
http://<JETSON_IP>:5000/
```

## Конфигурация

Основные настройки находятся в `Jetson Xavier/config.jsonc`.

| Раздел | Назначение |
| --- | --- |
| `network` | Адрес и порт UDP-сервера |
| `car` | Последовательный порт, тяга, нейтраль, рулевое управление и watchdog |
| `autopilot` | Сопоставление конусов, виртуальные точки и порог остановки |
| `vision` | Модель YOLO, камера, частота обработки и параметры детекции |
| `detection` | Соответствие классов модели типам конусов |
| `display` | Настройки визуализации |
| `video` | Кодеки, качество и формат записи |
| `timing` | Таймауты и задержки |
